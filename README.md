# GTA Sandbox

Мобильная тестовая версия Grand City Sandbox 3D.

Для запуска откройте сайт GitHub Pages на смартфоне в Chrome.

## 3D assets

The game bundles selected **Kenney** models converted to self-contained GLB data for reliable same-origin loading on GitHub Pages:

- City Kit (Commercial): city buildings and skyscrapers.
- Car Kit: sedans, sports cars, SUV, truck, garbage truck and police car.
- Nature Kit: detailed trees and pines.

Original models by Kenney are licensed **CC0 1.0**. Attribution is not required; see [ASSETS.md](./ASSETS.md) and the [source asset library](https://github.com/Hidencod/tge-assets).
